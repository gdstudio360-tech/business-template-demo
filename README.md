# Business Website Template — Presentation Demo

Premium demo website for solar, electrical and energy service companies.

## Purpose
This project demonstrates the Business website package: a responsive one-page site with premium styling, scroll animation, service sections, lead-generation CTA, process steps and an accreditation area.

## Demo notes
- This is a template demonstration, not a live trading company website.
- No form data is collected or stored.
- NICEIC, MCS Certified, RECC and TrustMark logos are shown as examples of how genuine client accreditations can be presented. They would be replaced or removed depending on the client’s actual certifications.
- Stock imagery is used for demonstration purposes and should be replaced with client photography where available.
